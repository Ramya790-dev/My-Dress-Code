# 👗 My Dress Code - Java Full Stack E-Commerce Website

My Dress Code is a modern Java Full Stack E-Commerce web application developed using Java Servlets, JSP, JDBC, MySQL, and Apache Tomcat. The application allows users to browse fashion products, manage their shopping cart, place orders, and make secure online payments through Razorpay. It also includes a comprehensive admin panel for managing products, categories, customers, and orders.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Ramya790-dev/My-Dress-Code.git
```

### 2. Open in Eclipse

Import as:

```
Existing Maven Project
```

### 3. Configure MySQL Database

- Create the database.
- Import the SQL tables.
- Update database credentials in:

```
DBConnection.java
```

### 4. Configure Apache Tomcat

- Apache Tomcat 10
- Add project to server
- Run the application
